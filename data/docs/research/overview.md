# 제한된 토큰으로 가장 멀리 가는 길: AI 개발 파이프라인 5종 실측 벤치마크

**기간**: 2026-07-27 ~ 07-31 KST · 4-Round Study

## 실험 개요

동일한 PRD(소셜 Todo 웹앱 — 회원가입·로그인 인증/인가 + 친구 관계)를 5가지 에이전트 파이프라인에 동시 투입해, 실제 API 토큰 사용량·비용·소요 시간·산출물 품질을 측정했다. 모든 수치는 각 에이전트 트랜스크립트의 usage 필드를 message 단위로 정산한 실측값이다.

## 공통 실험 조건

| 항목 | 값 |
|---|---|
| 모델 | claude-opus-5 ($5 / $25 per MTok), claude-sonnet-5 (정가 $3 / $15 per MTok) |
| 추론 강도 | 전 에이전트 effort: high |
| 제약 | Node.js 표준 라이브러리만 사용, 외부 패키지 금지 |
| 오케스트레이터 | Claude Fable 5 (측정 대상 외) |

## 이 문서를 인용할 때

이 코퍼스 전체는 `나침반(Compass)` 서비스가 개발 작업의 복잡도를 판정하고 파이프라인·비용을 추천할 때 근거로 인용하는 유일한 출처다. 여기 없는 수치나 결론은 추측하지 말고 "확인 불가"로 답해야 한다(가드레일 G4).
